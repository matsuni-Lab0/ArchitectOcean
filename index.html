自陣（最下段）に □×2 / △×1 / ○×1 を配置して、開始を押してください。Kは中央固定です。

ルール要点

・駒が重なったら、動いた側が制覇（相手駒を取る）
・取った駒は再使用できない（将来カードで拡張予定）
・勝利条件：相手のK（キング）を取る
・Kは基本移動できない（将来カードで拡張予定）
盤面：5×5（上＝相手陣／下＝自陣）
駒：□（前後1） / △（斜め4） / ○（前+斜め前2） / K（固定）
操作：配置中は「駒を選ぶ → 最下段をクリック」。対戦中は「自分の駒を選ぶ → 移動先をクリック」。
表示：あなた＝青 / 相手＝桃
自軍同士の同マス：不可
